## 🖥️ Installation
<br>

### 🪟 Windows `.exe` version

1. Download `Meowlorin.exe` from the **Releases** page.
2. If a `jre/` folder is provided, place it in the **same folder** as `Meowlorin.exe`.
3. Double-click `Meowlorin.exe` to start the game.
<br>

⚠️ If you get a message saying Java is required, either:

- Install [**Java JRE 21+**](https://adoptium.net/en-GB/temurin/releases/)
- Or make sure `jre/` is beside the `.exe` as a local runtime

---

### ☕ Option 2: `.jar` version (Java)

1. Install Java JRE 21 or later.
2. Download `Meowlorin.jar`.
